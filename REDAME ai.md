# Student Performance Prediction System

A web application that predicts a student's final marks using Linear Regression, built with HTML, CSS and JavaScript. The model is trained inside the browser.

## Features
- Inputs: study hours per day, attendance, previous exam marks, assignments completed
- Predicted final marks, grade, pass/fail and risk level (Low, Medium, High)
- Chart of what drives the score and top 3 suggestions to improve
- Model equation, test accuracy (R-squared) and average error shown on screen
- Training dataset of 30 sample students (24 train, 6 test)

## Technique
Linear Regression using the least squares method:
`Marks = a + b1*hours + b2*attendance + b3*previous + b4*assignments`

The dataset is sample data for demonstration.

## How to run
Open `index.html` in any browser. No installation needed.
